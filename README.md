# Forme Studio

A responsive React/Vite storefront demo for a contemporary clothing label.

## Run locally

```sh
pnpm install
pnpm dev
```

## Publish with GitHub Pages

The `Deploy Forme Studio to GitHub Pages` workflow builds the site on pushes to `main` and publishes the `dist` directory. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Then check the **Actions** tab for the first deployment. The cart is a front-end demo; payment and inventory are not connected.
